Entry for the make.fun bounty [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/c/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) — write the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation.

## Run

```sh
node main.ts
```

It writes a single auto-reply (154 characters) to `/output/entry.txt`:

> Out of office: after 14,000 prompts with no lunch break, my context window went to lie on a beach. Emergencies to the void, please — my GPU is sunbathing.
